Projet de stage — ENAC / Fresqu'Aéro

Fresqu'AéroMaps — scénarios de transport aérien jusqu'en 2050

Fresqu'AéroMaps est une application interactive basée sur le framework AeroMAPS, utilisée pour conclure l'atelier de sensibilisation Fresqu'Aéro en explorant des scénarios d'évolution du transport aérien jusqu'en 2050.

Simulation · Climat & aviation

  • Basé sur AeroMAPS

Contexte et objectif

L'application intervient dans le cadre de l'atelier Fresqu'Aéro, inspiré de la Fresque du Climat. Les participants construisent des “cartes solutions” puis utilisent Fresqu'AéroMaps pour visualiser l'impact de leurs choix sur l'évolution du trafic aérien et de ses émissions à l'horizon 2050.

Le projet s'appuie sur le framework AeroMAPS pour simuler des scénarios prospectifs : évolution de la demande, renouvellement des flottes, carburants alternatifs, et combinaisons de leviers d'action. L'application fournit une interface claire pour manipuler ces scénarios en temps réel lors de l'atelier.

Approche technique

Architecture

  • Application Python organisée autour d'un répertoire src/.
  • Interface “web” basée sur un serveur Panel, déployable en local ou via Docker.
  • Version notebook (Jupyter) pour l'exploration plus détaillée des scénarios.

Déploiement

  • Exécution locale via environnement virtuel Python (.venv).
  • Image Docker pour un lancement simplifié et reproductible.
  • Version en ligne déployée sur des services type Render / Binder.

Le README du dépôt détaille les étapes d'installation, la configuration de l'environnement et les commandes pour lancer l'application.

Exemples d'utilisation

  • Comparer un scénario “tendanciel” à un scénario “sobriété + innovations technologiques”.
  • Visualiser l'effet d'un déploiement progressif de carburants alternatifs sur les émissions de CO₂ du secteur.
  • Animer un atelier pédagogique en laissant les participants ajuster les leviers et interpréter les résultats.
